DIWALI VOTING — ADVANCED 3-MINUTE DESIGN

Open index.html after extracting this ZIP. Keep index.html, style.css,
timer-engine.js and script.js together. No installation/build required.

CHANGES IN THIS VERSION
- Header contains Home only: Quiz link removed.
- Every question has its own 03:00 countdown and circular timer indicator.
- First opening a question starts its timer; selecting a different answer does not reset it.
- Previous button and numbered visited-question buttons let you return to an earlier answer.
- You can change that answer while that question still has time remaining.
- An already-started timer continues while you visit another question, Home, a different tab,
  or close the browser. Refresh restores the original deadline and selected answer.
- At zero, the answer is locked and the next question opens automatically.
- If no name was selected at timeout, no vote is invented: review shows no selection.
- Review provides Edit for active questions, View for expired/locked questions.
- Final save locks the full ballot on this browser. There is no automatic final submission.
- Three-minute countdown turns red in the final 30 seconds.
- 14 colleagues, 12 questions, exactly 4 names each; tags remain hidden.
- Original black/burgundy/white design, toran, rangoli, glow and particles remain.
- Draft and timer survive refresh through browser localStorage.
- Browser storage failure is displayed rather than falsely claiming success.
- Arrow keys can move between the four names; reduced-motion preference is respected.

GITHUB PAGES

IMPORTANT — THIS IS STILL A FRONTEND DESIGN DEMO
No online backend, central database, admin login, real voting codes or aggregate results.
All draft and saved choices stay in this browser. Local timers and duplicate checks can
be bypassed by clearing storage, another browser/device, changing the local clock or
modifying code. This is not secure voting enforcement. A backend is needed for secure
shared office voting and authoritative timers. No hidden service credentials included.
A prior saved submission from the earlier demo remains locked on this same browser.
Google Fonts loads when online; fallback fonts work without internet.

TIMING CHOICE
The three-minute limit is PER QUESTION, starting when that question is first opened.
It does not pause when you leave the question. Expired choices can be viewed but not edited.
No name is selected automatically and no winner/tag is generated by this design demo.
