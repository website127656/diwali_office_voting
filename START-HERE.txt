DIWALI VOTING — PURE HTML / CSS / JAVASCRIPT

FILES
index.html  — all screens and page structure
style.css   — original black/burgundy/white styling and Diwali motion
script.js   — 12 questions, 4-name options, navigation, review, browser save
.nojekyll   — static publishing marker

OPEN ON YOUR COMPUTER
Extract the ZIP. Keep all three files in the same folder.
Double-click index.html. No Node.js, installation or build is needed.
Fonts load from Google Fonts when online; local fallback fonts work offline.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js and this guide into the repository ROOT.
   Do not upload only the ZIP, and do not leave index.html inside an extra folder.
3. In repository Settings → Pages, select Deploy from a branch.
4. Select main and / (root), then Save.
5. Open the website address GitHub provides after publishing.

FEATURES
- Original HTML's black, burgundy and white stripes, fonts and visual direction.
- Festive toran, rangoli, embers, fireworks, glowing progress and hover states.
- 14 colleagues, 12 office questions, exactly 4 distinct names per question.
- One selection, Previous/Next, answer review and edit, confirmation screen.
- No public tags, award names or winners.
- Mobile responsive rules and reduced-motion support.

THIS PACKAGE IS A DESIGN DEMO
Answers are saved ONLY in localStorage in the current browser.
This demo does NOT collect everyone's votes in a shared database.
After saving, that browser is directed to confirmation instead of voting again.
Clearing browser storage, another browser/device, or incognito bypasses this local
restriction. It is NOT secure person-level duplicate-voting protection.
For real office voting, connect a backend/database with one-time tokens or login.
The UI clearly identifies the browser-only demo; no server submission is claimed.
If browser storage is disabled, it reports the error instead of claiming success.

EDITING
Change employee names and questions in the config object in script.js.
options(index) picks four consecutive names, rotating across questions.
Only those four nominees are selectable for that question. Every voter sees the
same four options for each question. No random winners are generated.
Change colours in style.css under :root. Keep these filenames together.

PRIVACY
No individual answers are sent to any server by these files.
Google Fonts receives normal font requests when online.
No admin password, voting codes, API secrets or fake aggregate results included.
